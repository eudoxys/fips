# CLAUDE.md

Guidance for Claude when working in the `eudoxys/fips` repository.
General Eudoxys package conventions are in the `eudoxys-package` skill
(https://github.com/eudoxys/claude); this file records only what is
specific to this package.

## What this is

A small accessor for US state and county reference data keyed by Census
Bureau FIPS codes: state and county names, FIPS codes, county centroids
and geohashes, time-zone offsets and DST, interconnection (`SYSTEM`),
reliability organization (`RO`), and market/balancing region (`REGION`).
Python >= 3.11, pandas only, alpha. All data is embedded in the modules as
CSV text; there is no download, cache, or package data file.

- Docs site: https://www.eudoxys.com/fips (pdoc from docstrings)
- Maintainer: David P. Chassin
- CLI entry point: `fips` -> `fips.cli:main`

## Where things are

  Read it first instead of listing folders.

No sibling Eudoxys dependencies.

## Core conventions

- `States` and `Counties` are `pd.DataFrame` subclasses built from a CSV
  string in the module; `State` and `County` select one row by keyword
  (`State(ST="CA")`, `County(ST="CA",COUNTY="Alameda")`) and expose its
  columns as attributes.
- The county table is parsed once per process (`_counties()`), and
  `County`/`State` look up rows in indexed tables cached per key set
  (`_counties_by()`, `_states_by()`). These cached frames are shared:
  never modify them; `Counties` returns a copy (#15).
- Columns are upper case. `FIPS` is a zero-padded string (`"06"`,
  `"06001"`) even though the embedded table stores it as an integer.
- `(ST,COUNTY)` and `FIPS` are each unique keys for counties. Independent
  cities keep a ` City` suffix; use `TYPE`, not the name, to identify one.
- `States` rows outside the US (`with_canada`, `with_mexico`) have
  `COUNTRY` other than `"USA"`, an ISO 3166-2 `ST`, and package-specific
  `FIPS` codes (`C0`-`C9`, `M0`) that are not real FIPS codes. `RO` is
  empty where there is no NERC regional entity (AK, HI).
- Valid `REGION` and `TYPE` values are the keys of
  `fips.counties.REGIONS` and `fips.counties.TYPES`.
- The `REGION` column of the county table is generated by
  `fips/_data/build_counties.py`; every other column is curated by hand.

## Style

House style: no spaces after commas in calls and signatures
(`Counties(use_index=["ST"],selection=["CA"])`), type-annotated arguments,
dashed-underline docstring sections. Match it; don't reformat code you
aren't changing.

## Build, test, docs

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install --upgrade pip && pip install -e . pytest
pytest
python3 fips/_data/build_counties.py --check
python .github/check_manifest.py
make docs      # pdoc into docs/, as in deploy-pages.yaml
make test      # same as the venv + pytest steps above
```

Everything is fast and offline; the full suite runs in seconds. CI
(`validate.yaml`) installs non-editable and runs pylint (informational) on
`fips/*.py` and pytest on Python 3.11-3.14.

## Known rough edges (don't "fix" silently; mention or ask)

- County vintage predates the 2019 (Alaska) and 2022 (Connecticut) Census
  changes, and the table has no recorded source (#7).
- `REGION` follows FERC's market regions by majority of population
  (source and rule in `fips/_data/README.md`, #8). Only CA, IL, and NV
  have county-level regions; KY, MS and other split states use one
  region, and `CA Los Angeles` as `LADWP` is pending review.
- The CLI's `-o|--output` applies only to `-f csv`; with the default
  table format it is ignored and the table goes to stdout.
- The CLI's `--header`/`--index` are hidden, deprecated aliases of
  `--no-header`/`--no-index`, kept so existing scripts still work (#11).

## Working rules

- Don't commit `docs/` or other generated output; docs are built by CI.
- To change a region, edit `fips/_data/build_counties.py` and run it with
  `--write`; never hand-edit the `REGION` column. Update the counts in
  `fips/_data/README.md`.
- When a column, signature, or output changes, update the module
  docstring example, the package docstring in `fips/__init__.py`, and
  `README.md` in the same PR. Regenerate example output with
  `pd.options.display.width = None`, `display.max_columns = None`, and
  `display.max_rows = 10`.
- Update `MANIFEST.md` when adding, moving, or deleting files, and run
  `python .github/check_manifest.py`.
- Tests are pytest functions in `fips/_test/test_*.py`; shared fixtures
  and the valid `SYSTEM`/`RO` value sets are in `fips/_test/conftest.py`.
  Whole-table contracts go in `test_data.py`.
- Conventional small test case: `fips CA Alameda` /
  `County(ST="CA",COUNTY="Alameda")`.
