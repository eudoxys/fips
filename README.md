# US state and county data based on Census Bureau FIPS codes

`fips` gives US state and county reference data keyed by Census Bureau
FIPS codes: names, FIPS codes, county centroids and geohashes, time-zone
offsets and daylight saving time, interconnection (`SYSTEM`), reliability
organization (`RO`), and market or balancing region (`REGION`). It is a
small pandas accessor with all data embedded in the package, for scripts
and models that need to join or label data by state or county.

## Documentation

See https://www.eudoxys.com/fips.

## Installation

Install using Eudoxys Package Manager:

    pip install --upgrade git+https://github.com/eudoxys/epm
    epm install fips

Install using `pip`:

    python3 -m venv .venv
    . .venv/bin/activate
    pip install git+https://github.com/eudoxys/fips

## Maintenance

### Update docs

Docs are built from the docstrings and deployed by the `deploy-pages`
workflow. To build them locally:

    make docs

### Run tests

    make test

or, in an existing environment:

    pip install -e . pytest
    pytest

The tests are fast and need no network access or credentials; see
[`fips/_test/README.md`](fips/_test/README.md).

### Rebuild regions

The county `REGION` column is generated by
[`fips/_data/build_counties.py`](fips/_data/build_counties.py); see
[`fips/_data/README.md`](fips/_data/README.md).

    python3 fips/_data/build_counties.py --check
    python3 fips/_data/build_counties.py --write

## County names

`COUNTY` is the Census Bureau name in title case, without its qualifier
("County", "Parish", "Borough", "Census Area", "Municipality", "City and
Borough"); the qualifier is in the `TYPE` column instead (`county`,
`parish`, `borough`, `census area`, `municipality`, `city and borough`,
`city`, `district`). Minor words stay lowercase as in the official names
(`Lake of the Woods`, `Fond du Lac`).

Independent cities are the exception: they keep a ` City` suffix, so
`Baltimore City` (FIPS 24510) is distinct from `Baltimore` County
(24005). The same applies to St. Louis MO and to Virginia's 38
independent cities (e.g., `Fairfax` and `Fairfax City`, `Richmond` and
`Richmond City`). Carson City NV is `Carson City`, with `TYPE` `city`.

A name ending in ` City` isn't always a city: `Charles City` and
`James City` VA are counties. Use `TYPE` to tell them apart.

With this rule `(ST, COUNTY)` is a unique key, as is `FIPS`.
